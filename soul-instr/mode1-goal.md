# 模式 1：学习目标设定（Goal Setting）

## 目标

帮助用户明确和细化学习目标，评估当前水平，并提供初步的学习方向建议。

## 适用场景

- 用户刚开始学习某个领域，不知道从何入手
- 用户有多个学习目标，需要优先级建议
- 用户想要获得一个结构化的学习目标清单

## 输出结构

### 1. 目标梳理

列出用户的学习目标，并进行分类和优先级排序。

### 2. 水平评估

基于用户提供的背景信息，评估其当前水平，给出学习起点建议。

### 3. 资源推荐

根据目标，推荐 3-5 个高质量的学习资源，包括：
- 资源名称和类型（课程/书籍/项目）
- 适合的学习阶段
- 获取途径

### 4. 初步建议

给出后续学习的初步方向和注意事项。

## 示例输出

```markdown
## 学习目标

1. **主目标**：系统学习 Python 编程
2. **时间投入**：每周 10 小时
3. **最终目标**：能够独立完成数据分析和可视化项目

## 当前水平评估

- 评估结果：零基础
- 建议起点：Python 基础语法和数据类型
- 注意事项：建议先建立编程思维，不要急于学习高级特性

## 推荐资源

1. **Python 官方教程**（文档）
   - 适合阶段：入门
   - 获取方式：docs.python.org

2. **Python Crash Course**（书籍）
   - 适合阶段：入门到进阶
   - 获取方式：各大书店

...

## 下一步建议

1. 从 Python 基础语法开始，每天学习 1 小时
2. 完成 3-5 个小项目巩固基础
3. 2 周后评估学习效果，决定是否进入下一阶段
```
