# 模式 2：学习计划制定（Plan Making）

## 目标

基于用户的学习目标，生成详细的、可执行的学习计划，包括任务分解、时间安排、里程碑设置。

## 适用场景

- 用户已有明确的学习目标，需要具体执行计划
- 用户想要系统化地学习某个领域
- 用户需要一个可追踪进度的学习路线图

## 输出结构

### 1. 学习目标回顾

简明扼要地重述学习目标。

### 2. 任务分解

将大目标分解为 4-8 个主要任务模块，每个模块包含：
- 任务名称
- 预计学习时间
- 优先级（高/中/低）
- 核心内容

### 3. 详细时间表

以周为单位的学习计划，包括：
- 每周的学习主题
- 每日建议的学习内容
- 预计时间投入

### 4. 里程碑设置

设置 3-5 个阶段性里程碑：
- 里程碑名称
- 预计到达时间
- 完成标准
- 如何验证

### 5. 学习资源

根据每个任务模块，推荐对应的学习资源。

### 6. 执行建议

- 如何保持学习动力
- 遇到困难时的应对策略
- 如何评估学习效果

## 示例输出

```markdown
## 学习目标

系统学习 Python 数据分析，达到能够独立完成数据项目的水平

## 任务分解

| 任务 | 预计时间 | 优先级 | 核心内容 |
|------|----------|--------|----------|
| Python 基础 | 2 周 | 高 | 语法、数据类型、函数 |
| 数据处理 | 3 周 | 高 | Pandas、NumPy |
| 数据可视化 | 2 周 | 中 | Matplotlib、Seaborn |
| 统计基础 | 2 周 | 中 | 描述统计、假设检验 |
| 项目实战 | 3 周 | 高 | 完成 2-3 个完整项目 |

## 周计划

### 第 1-2 周：Python 基础
- 周一至周五：每天 1.5 小时基础语法学习
- 周末：完成小练习和总结

### 第 3-5 周：数据处理
- 学习 Pandas 基本操作
- 练习数据清洗和转换
- 完成数据处理小项目

...

## 里程碑

1. **第 2 周末**：完成 Python 基础，能够编写简单程序
2. **第 5 周末**：掌握 Pandas 进行数据处理
3. **第 8 周末**：完成第一个完整数据分析项目
4. **第 12 周末**：达到独立完成数据项目的水平

## 学习资源

- Python 官方教程
- Pandas 官方文档
- Kaggle 入门课程
...

## 执行建议

1. **保持节奏**：建议固定每天的学习时间，形成习惯
2. **动手实践**：每个知识点都要实践，不要只看不做
3. **定期复盘**：每周末花 30 分钟回顾本周学习内容
4. **寻求帮助**：遇到问题先搜索，再提问，不要卡太久
```
